# How to Contribute (5-minute guide)

You do **not** need to know git. Everything below works in the browser.

## Edit a doc

1. Open the file on GitHub.
2. Click the **pencil icon** (top right of the file).
3. Make your changes. Markdown basics are at the bottom of this page.
4. Scroll down, write a short message like `Add motor thrust data`, and click **Commit changes**.

## Add a new file (research, meeting notes, etc.)

1. Go to the folder (for example `research/`).
2. Click **Add file → Create new file**.
3. Name it using the format below, paste in the matching template, and commit.

## Upload files (PDFs, images, CAD exports)

1. Go to the folder.
2. Click **Add file → Upload files** and drag them in.
3. Keep files under 25 MB. For big CAD files, put them in the team Drive/Onshape and link them instead.

## Work on a task

1. Go to **Issues → New issue** and pick a template (Task, Research, or Bug).
2. Assign yourself and set the **Subteam** field on the board.
3. When you start, drag the card to **In Progress**.
4. When it's done and someone has checked it, close the issue. It moves to **Done** automatically.

## Naming rules

| Type | Format | Example |
|---|---|---|
| Research | `YYYY-MM-DD-topic.md` | `2026-10-12-px4-vs-ardupilot.md` |
| Meeting notes | `YYYY-MM-DD.md` | `2026-10-14.md` |
| Images | `topic-description.png` | `frame-top-view.png` |

Lowercase, dashes instead of spaces.

## This repo is public

Do **not** commit:
- Passwords, API keys, or WiFi credentials
- Phone numbers, home addresses, or other personal info
- Anything a sponsor asked us to keep private
