# Pathfinder

Autonomous UAV project under Purdue Momentum.

**Semester 1 goal (due first week of December 2026):** a physical drone that takes off, hovers, flies a hard-coded forward leg, and lands.
**Semester 2 goal (16 weeks):** autonomy.

## Tech stack

- **CAD:** SolidWorks / Onshape
- **Flight controller:** Pixhawk
- **Firmware:** PX4 or ArduPilot (decision pending, see research/)
- **Onboard compute:** Raspberry Pi or Jetson (decision pending)
- **Languages:** Python, C++

## Milestones (Semester 1)

- [ ] Frame and components selected, BOM finalized
- [ ] Parts ordered
- [ ] Frame assembled
- [ ] Electronics wired and flight controller configured
- [ ] Motor and ESC bench test
- [ ] Tethered hover test
- [ ] Free hover
- [ ] Hard-coded forward leg and landing (MVP)

## How work flows

1. Every task is a GitHub **Issue** using one of the templates.
2. Issues live on the **Project board**: `Backlog → To Do → In Progress → Review → Done`.
3. Docs and research are Markdown files in this repo. Edit them right in the browser.
4. If it isn't on the board, it isn't happening.
